# خريطة بنية الموقع (Sitemap) — رفيق القلوب

## التسلسل المنطقي المعتمد

```
الرئيسية (/) 
  → الحوار البحثي (/hiwar)
    → النتيجة: الأبواب + الكلمات + المادة المسترجعة + التنظيم الآلي
      → صفحة الباب (/maktaba/[bab])           — الأبواب الاثنا عشر
        → بطاقة المصدر (/maktaba/kutub/[slug]) — سجل المصادر المعتمدة
          → فتح المصدر الأصلي (رابط خارجي موثق: al-badr.net / binbaz.org.sa)
      → أسئلة بحث ذات صلة (روابط إلى /hiwar?q=…)
  → الاستبانة البحثية (/hala) — ملاحة ثلاث خطوات تنتهي بمسار إلى /hiwar
  → المكتبة المعتمدة (/maktaba) — سجل المصادر + تصنيف الأبواب
```

## جدول الصفحات

| المسار | النوع | المحتوى | الروابط الصادرة |
|---|---|---|---|
| `/` | ثابت | تعريف الأداة، كيف تعمل (٤ خطوات)، حدود الأداة، أبواب البحث الـ١٢، المصادر المعتمدة | `/hiwar`, `/hala`, `/maktaba`, `/maktaba/[bab]`, `/maktaba/kutub/[slug]`, `/wasfa` |
| `/hiwar` | تفاعلي (خادم) | وحدة البحث: إدخال الوصف، استرجاع `/api/research`, عرض النتيجة كاملة | `/maktaba/[bab]`, `/maktaba/kutub/[slug]`, روابط خارجية للمصادر، `/hiwar?q=` (أسئلة ذات صلة) |
| `/hala` | تفاعلي (عميل) | استبانة ثلاث خطوات: المجال ← التضييق ← المسار | `/hiwar?q=…`, `/maktaba/[bab]` |
| `/maktaba` | ثابت | سياسة الاعتماد، سجل المصدرين (البدر/ابن باز)، تصنيف الأبواب الـ١٢ مع أعداد المقاطع | `/maktaba/[bab]`, `/maktaba/kutub/[slug]`, خارجي |
| `/maktaba/[bab]` | SSG ×12 | عنوان الباب ورقمه، وصف، كلمات مفتاحية، المقاطع المسترجعة ببيانات المصدر، أسئلة ذات صلة، أبواب مرتبطة | `/maktaba/[bab]` أخرى, `/hiwar?q=…`, `/maktaba/kutub/[slug]`, خارجي |
| `/maktaba/kutub/[slug]` | SSG ×2 | بطاقة المصدر: التسجيل، المعتمِد، التاريخ، الملاحظات، المقاطع المفهرسة (أو «قيد التوثيق» لابن باز) | `/maktaba/[bab]`, خارجي للأصل |
| `/wasfa` | ثابت | إشعار واضح: «الوصفة» لم تعد جزءاً من الأداة + تحويلات | `/hiwar`, `/hala`, `/maktaba` |
| `404` | ثابت | صفحة غير موجودة | `/`, `/maktaba` |
| `/api/research` | POST خادم | مسار البحث الكامل (سلامة←فتوى←موضوعات←كلمات←استرجاع←تنظيم) + سجل تتبع في قاعدة البيانات | — |
| `/api/health` | GET خادم | فحص صحة الاتصال بقاعدة البيانات | — |

## قواعد التسلسل
1. كل نتيجة بحث تنتهي بمسار واحد على الأقل إلى **مصدر معتمد مرئي** (اسم + موضع + رابط أصل).
2. لا صفحة تعرض مادة دينية بلا بطاقة مصدر مرفقة.
3. «أسئلة ذات صلة» و«الأبواب المرتبطة» تنشأ من التصنيف الرسمي فقط — لا ارتباطات عشوائية.
4. `/wasfa` لا تعرض أي محتوى وصفي؛ إشعار توقف الميزة فقط.
