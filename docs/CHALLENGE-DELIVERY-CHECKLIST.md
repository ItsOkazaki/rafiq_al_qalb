# قائمة التسليم النهائية

## قبل نشر النسخة النهائية

- [ ] GitHub public ومصدر المشروع قابل للتشغيل.
- [ ] لا توجد مفاتيح أو `.env` أو logs أو traces في Git.
- [ ] لا توجد بيانات مستخدمين حقيقية في benchmark.
- [ ] source registry وحقوق/مصادر المحتوى محدثة.
- [ ] `npm run typecheck` ناجح.
- [ ] `npm run lint` ناجح.
- [ ] `npm run build` ناجح.
- [ ] benchmark كامل 40 سؤالاً شُغّل على البيئة النهائية.
- [ ] `benchmarks/results/latest.json` محفوظ محلياً للفريق وأرقامه من تشغيل فعلي.
- [ ] conflict fixture شُغّل.
- [ ] UX test أُجري وسجلت الخلاصة في ملف النتائج.
- [ ] demo URL يعمل.
- [ ] العرض التقديمي يذكر بوضوح: AI contribution + baseline comparison + failure handling.
- [ ] الفيديو النهائي لا يتجاوز دقيقتين.
- [ ] تم تدقيق أي عبارة «literal quote» مقابل `excerptType`.
- [ ] تم وضع tag للإصدار المستقر، مثل `challenge-final-2026`.

## ملاحظة التوقيت

هذا المستودع المطوّر قبل يوم التحدي يجب التعامل معه كخط أساس مسبق. وفق قواعد التحدي، الأعمال التي يجب احتسابها ضمن أيام التنفيذ هي فقط التغييرات التي ينفذها الفريق فعلياً داخل نافذة التحدي؛ لا تعيدوا كتابة التاريخ بأثر رجعي.
