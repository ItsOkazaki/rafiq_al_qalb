# خطة الـDelta لأيام التحدي

هذه الخطة ليست ادعاءً بما تم إنجازه. استخدموها لتحديد ما سيُنفذ فعلياً داخل نافذة التحدي بعد تجميد baseline.

## اليوم الأول

- تشغيل baseline benchmark على البيئة المرجعية.
- ضبط hybrid weights والـsemantic candidate pool بناءً على القياس.
- توثيق الحالات التي يفوز فيها semantic retrieval والحالات التي يفشل فيها.

## اليوم الثاني

- تحسين Evidence Gate بناءً على أخطاء benchmark الحقيقية.
- تقوية conflict resolution / UI بحسب ملاحظات المراجعة.
- تنفيذ UX test ثم إصلاح أعلى نقاط الاحتكاك.

## اليوم الثالث

- إعادة تشغيل benchmark النهائي.
- مقارنة delta بالأرقام الفعلية.
- تثبيت النسخة، تحديث الوثائق، تجهيز demo/video/presentation.

## قاعدة الاحتساب

فقط التغييرات الفعلية التي ينفذها الفريق أثناء الأيام المحددة ينبغي أن تظهر على أنها challenge-day work.
