# فهرس وثائق رفيق القلوب

الوثائق مرتّبة بحسب من يقرأها. كل ملف يصف حالة هذا الـcommit، وما ليس منفّذاً مكتوب صراحةً.

> **لماذا ٢٠ وثيقة لا أكثر؟** حُذفت قبيل التسليم كل وثيقة كانت عمليةً داخلية أو قائمة مهام
> أو نسخة مكررة من موضع آخر (خطط أيام التنفيذ، قوائم التسليم والتحقق الداخلية، بروتوكول
> اختبار تجربة لم يُنفَّذ ونموذجه الفارغ، خريطة صفحات يكررها `README`، مجموعة سيناريوهات
> حلّت محلّها مجموعة القياس التنفيذية). الباقي أدناه إما دليل يُفتح أمام اللجنة، أو توثيق
> مصدر/ترخيص، أو وصف مسار تقني لا يوجد في موضع آخر.

## اصطلاحات

- **لا أرقام مكتوبة يدوياً**: كل رقم أداء يأتي من تشغيل حقيقي، والدليل الآلي الملتزم في Git هو
  `benchmarks/results/latest.json` (يُكتب بمشغّل القياس وحده، ولا يتغير إلا بتشغيل **كامل**؛
  التشغيل الجزئي يكتب `results/partial-N.json` غير المتعقَّب).
- **لا ادعاء غير مُتحقَّق**: ما لم يُشغَّل فعلاً يوصف بأنه «لم يُنفَّذ بعد» أو «غير موصول».
- **لا عبارة معلَنة تُرفض**: كل synonym وكلمة مفتاحية وسؤال تقترحه الواجهة (٥٣٩ عبارة) يمرّ
  آلياً على البوابات الأربع في الاختبارات، ويُشترط ألا يُرفض أي منها.
