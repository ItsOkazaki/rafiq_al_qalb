# فهرس وثائق رفيق القلوب

الوثائق مرتّبة بحسب من يقرأها. كل ملف يصف حالة هذا الـcommit، وما ليس منفّذاً مكتوب صراحةً.

## للجنة التحكيم والمراجع التقني

| الملف | لماذا تقرأه |
|---|---|
| `../README.md` | نظرة كاملة: المشكلة، الحل، المعمارية، الأوامر، الحالة |
| `ARCHITECTURE.md` | المسار الفعلي للطلب: البوابات، الاسترجاع، طبقة النموذج، وما ليس موصولاً |
| `BENCHMARK.md` | مجموعة 40 حالة ثابتة، المقاييس، وأوامر التشغيل |
| `VERIFICATION-AUDIT.md` | مقابلة المواضع (جزء/صفحة) للمصادر المدرجة |
| `SOURCES-AND-LICENSES.md` | جرد المصادر وأعداد المقاطع وطبيعة كل مصدر |
| `PRESENTATION-ALIGNMENT.md` | ما يُقال أمام اللجنة وما لا يُقال |
| `JUDGE-RUBRIC-MAP.md` | ربط كل معيار تحكيم بدليل قابل للفتح في الكود |

## اصطلاحات

- **لا أرقام مكتوبة يدوياً**: كل رقم أداء يأتي من `benchmarks/results/latest.json` (غير متعقّب في Git).
- **لا ادعاء غير مُتحقَّق**: ما لم يُشغَّل فعلاً يوصف بأنه «لم يُنفَّذ بعد» أو «غير موصول».
