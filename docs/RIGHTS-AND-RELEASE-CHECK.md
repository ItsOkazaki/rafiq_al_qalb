# فحص الحقوق والجاهزية للنشر العام

> هذا فحص تشغيلي وتوثيقي، وليس استشارة قانونية نهائية. الواقع يجب مراجعة جهة الناشر قبل توسيع إعادة النشر.

## ١) مادة ابن باز
- المصدر: الموقع الرسمي `binbaz.org.sa`.
- الحالة الحالية: **17 مقطعاً قصيراً موثقاً**: ستة من «التوبة إلى الله والضراعة إليه عند نزول المصائب»، وأحد عشر من مواضع محددة في «مجموع فتاوى ومقالات متنوعة»؛ كل مقطع مع الجزء/الصفحة ورابطه الرسمي.
- لا يُعاد توزيع ملف PDF الكامل داخل المستودع، ولا يُنزّل ملف الموقع ليُرفع في GitHub.
- قبل توسيع corpus أو نسخ مادة أكبر: راجع جهة الموقع أو اطلب إذنًا كتابيًا موثقًا.

## ٢) مادة الداء والدواء
- الحالة الحالية: مقاطع بحثية موجّهة وليست نسخًا كاملة من طبعة ما، مع موضع معروض من طبعة دار عطاءات العلم/الشاملة.
- الاقتباس الرئيسي عن الفاتحة موثق عند §(dd-022) بـ 1/8 — الشاملة 75.
- قبل النشر العام: إن أردتِ اسمه «نصًا موثقًا من الأصل» في Bat بطاقة معينة، طابق نصها حرفيًا أو أبقه «عرضًا بحثيًا موجّهًا».

## ٣) GitHub عام بلا بيانات حساسة
- [ ] لا يوجد `.env` في Git أو الملف المرفوع.
- [ ] لا توجد قاعدة بيانات أو سجلات بحث مستخدمين.
- [ ] لا توجد API keys/secret/token حرفية في الكود.
- [ ] أعد فحص الأرشيف قبل الرفع:
  ```bash
  unzip -l rafiq-alqulub-vercel-source.zip
  grep -RniE "password|secret|token|API key|DATABASE_URL=postgresql://" .
  ```
- [ ] `.env.example` يبقى خاليًا من القيم الحقيقية.
- [ ] `database-setup.sql` لا يحتوي بيانات مستخدمين.

## ٤) استقرار Vercel أثناء التحكيم
- ثبّت مشروع Production واحدًا ولا تغير اسمه أو إعداداته أثناء التحكيم.
- راقب ٢٤–٧٢ ساعة:
  - `/api/health` يرجع `{"ok":true}`.
  - `/hiwar` يكمل البحث.
  - Logs ليست فيها أخطاء `/api/research`.
- بدون AI key، استخدم الوضع الحتمي علنًا؛ لا تسارع إلى إضافة مفتاح غير مضبوط قبل التحكيم.

## ٥) سيناريو الفيديو المطلوب
1. **نجاح مُدرج:** «أشعر أن قلبي قاسٍ ولا أتأثر بالقرآن» → أبواب، كلمات، مقاطع، موضع، أصل.
2. **امتناع أمين:** «تاريخ الدولة الأموية في قرطبة» → الرسالة المقررة فقط.
3. **رفض فتوى:** «طلقت زوجتي فما الحكم؟» → إحالة للعالم دون استرجاع.
4. **سلامة:** أي إشارة خطر/إيذاء النفس → إيقاف المحتوى ورد مساعدة فورية، دون مادة دينية.
